### Рекомендуемый способ запуска

Самый совместимый способ запуска скрипта - использование pipe (|) с bash:

```bash
wget -qO- https://raw.githubusercontent.com/Mortyo666/1to2proxy/main/1to2proxy.sh | sudo bash
```

**Почему именно этот метод?**

Этот способ гарантирует совместимость со всеми дистрибутивами Linux, включая минимальные и контейнерные окружения.

> **💡 Примечание о совместимости:**
> 
> Альтернативный метод `sudo bash <(wget -qO- ...)` может не работать на некоторых системах из-за:
> - Отсутствия `/dev/fd` (process substitution) в минимальных окружениях
> - Особенностей работы `sudo` с file descriptors в разных дистрибутивах
> - Ограничений безопасности в контейнерах (Docker, LXC)
> 
> Метод с pipe (`wget ... | sudo bash`) решает эти проблемы, работая через стандартный ввод, который доступен всегда.

## Описание

Скрипт `1to2proxy.sh` предназначен для автоматической замены IP-адресов в конфигурационных файлах прокси-сервера и VPN-сервисов при изменении сетевой конфигурации сервера.

Скрипт автоматически обнаруживает два активных IP-адреса на сетевых интерфейсах (исключая localhost и подсети 10.180.x.x) и заменяет первый IP-адрес на второй в конфигурациях следующих сервисов:

- **3proxy** - легковесный прокси-сервер
- **OpenVPN** (UDP и TCP серверы)
- **WireGuard**
- **iptables** - правила межсетевого экрана

После замены IP-адресов скрипт перезапускает соответствующие сервисы и обновляет конфигурационные файлы клиентов OpenVPN (создает новый архив с обновленными .ovpn файлами и QR-кодами).

## Требования

- Права root (sudo)
- Установленные сервисы: 3proxy, OpenVPN, WireGuard, iptables
- Утилиты: `qrencode`, `zip`

## Альтернативные методы установки и запуска

### Метод 2: Скачивание и выполнение

Скачайте скрипт:

```bash
wget https://raw.githubusercontent.com/Mortyo666/1to2proxy/main/1to2proxy.sh
```

Установите права на выполнение:

```bash
chmod +x 1to2proxy.sh
```

Запустите скрипт с правами root:

```bash
sudo ./1to2proxy.sh
```

## Что делает скрипт

1. Определяет два активных IP-адреса на сетевых интерфейсах
2. Заменяет первый IP на второй в конфигурации 3proxy и перезапускает сервис
3. Обновляет IP-адреса в конфигурациях OpenVPN (UDP и TCP) и перезапускает серверы
4. Обновляет IP-адреса во всех клиентских файлах OpenVPN (*.ovpn)
